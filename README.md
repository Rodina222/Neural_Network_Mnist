# Neural Network Implementation in Python
This project involves building a simple neural network from scratch in Python, using the MNIST dataset as the input data. The notebook demonstrates how to implement core components like activation functions and evaluates the model's performance using accuracy metrics.

## Project Overview

* **Objective:** Develop a neural network from scratch using Python, focusing on understanding the fundamentals of neural network architecture and function implementation.
* **Dataset:** MNIST - a collection of 70,000 images of handwritten digits (0-9) with each image being 28x28 pixels.
* **Key Functions:** Activation function (sigmoid), accuracy calculation, and basic neural network operations.
